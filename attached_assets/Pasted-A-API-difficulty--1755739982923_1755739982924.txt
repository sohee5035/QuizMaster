A. 변경 요약

난이도 표시 제거

어디에서도 난이도 뱃지/칩/텍스트를 렌더링하지 않음.

API 응답에 difficulty가 있어도 프론트에서 무시.

해설은 “원문 그대로” 노출

줄바꿈/괄호/경로 등을 가공 없이 그대로 보여줌.

마크다운 변환/요약/접기 사용 금지.

글자 그대로 복사 가능하도록 white-space: pre-wrap 스타일 적용.

메인 화면 추가 (게스트 시작형)

본선 25.09.12 (금) 16:00

B. 화면 스펙
B-1) 메인(Home)

타이틀: KB 외환 마스터

일정/카피 3줄 고정 문구(위 문구 그대로)

CTA: 게스트 – 문제풀이 시작

클릭 시 /api/session/start(mode='study') 호출 → 문제 화면으로 이동

B-2) 문제 화면(Learning)

진행상황 바(예: 1 / 2)만 표시

문제 지문(stem)

보기:

MCQ: 4개(순서 랜덤)

OX: O / X

선택 즉시 판정 → 상단에 “정답입니다 / 오답입니다” 알림

해설 박스: 네가 준 원문 그대로 렌더

다음 진행은 반드시 [다음 문제] 버튼으로

표시 금지: 난이도 칩/난이도 텍스트, 불필요 라벨(‘객관식’ 배지 등)

문제 해설 항상 노출 흐름

답 선택 → /api/session/:id/answer → {isCorrect, explanation} 수신

결과 배너 표시 + 설명 박스 그대로 렌더

[다음 문제] 버튼이 활성화될 때까지 다른 보기 클릭 비활성

E. 서버(Express) 체크리스트

/api/session/start : 세션 생성 후 첫 문제 반환

/api/session/:id/next : 다음 문제 + 섞인 보기 순서 반환

/api/session/:id/answer : 채점 → explanation 원문 그대로 전달

응답 DTO에 difficulty 포함되어도 프론트는 미사용
