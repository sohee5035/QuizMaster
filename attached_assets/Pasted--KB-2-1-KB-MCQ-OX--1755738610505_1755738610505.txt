📘 KB외환마스터 연습앱 – 구현 명세서 (테스트 2문항 버전)
1. 목표

KB외환마스터 시험 대비 연습 웹앱

문제은행 기반: 사지선다(MCQ) + OX 혼합

기능:

문제 보기 랜덤 섞기

정답/오답 판정 후 항상 해설 출력

반드시 “다음문제” 버튼을 눌러야 다음 문제로 이동

2. 주요 기능 요약

학습 모드: 문제 하나씩 풀기, 해설 확인, 다음문제 버튼으로 진행

모의고사 모드: 일정 수 문제 세트, 제출 후 결과 확인

오답노트 모드: 틀린 문제 다시 풀기

※ 이번 테스트는 문항 2개만 등록해 진행

4. DB 스키마 (SQLite)
CREATE TABLE questions (
  id TEXT PRIMARY KEY,
  type TEXT,          -- 'MCQ' or 'OX'
  stem TEXT NOT NULL,
  explanation TEXT,
  tags TEXT,
  difficulty INTEGER,
  source TEXT
);

CREATE TABLE choices (
  id TEXT PRIMARY KEY,
  question_id TEXT,
  content TEXT,
  is_correct INTEGER,
  FOREIGN KEY(question_id) REFERENCES questions(id)
);

CREATE TABLE sessions (
  id TEXT PRIMARY KEY,
  mode TEXT,          -- 'study','mock','review'
  started_at DATETIME,
  ended_at DATETIME
);

CREATE TABLE responses (
  id TEXT PRIMARY KEY,
  session_id TEXT,
  question_id TEXT,
  choice_id TEXT,
  selected_boolean INTEGER,
  is_correct INTEGER,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

5. API 요약

POST /api/session/start → 세션 생성 + 첫 문제 반환

GET /api/session/:id/next → 다음 문제 반환 (보기 랜덤 포함)

POST /api/session/:id/answer

body (MCQ): { sessionQuestionId, selectedChoiceId }

body (OX): { sessionQuestionId, selectedBoolean: true|false }

resp: { isCorrect, explanation, nextReady: true }

POST /api/session/:id/finish → 세션 종료 요약

6. 동작 규칙

문제 로드 시 보기 순서 무작위 섞기(Fisher–Yates)

사용자가 답 선택 → 정답/오답 표시

해설 항상 노출

“다음문제” 버튼 클릭 시 다음 문제 진행

오답일 경우 responses 테이블에 기록

7. 화면 요건
